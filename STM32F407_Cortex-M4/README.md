Build it

From the project root:

cd STM32F407_Cortex-M4
make

You should eventually see:

==========================================
 STM32F407 BUILD SUCCESS
==========================================


Generated files:
  build/scrambler_stm32.elf
  build/scrambler_stm32.hex
  build/scrambler_stm32.bin
  build/scrambler_stm32.map

Then:

ls -lh build/

should show:

scrambler_stm32.elf
scrambler_stm32.hex
scrambler_stm32.bin
scrambler_stm32.map
obj/

Note: the .o files and the four final firmware files are generated by make; you should not create empty placeholder files for them.
